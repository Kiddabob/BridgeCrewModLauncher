icon, and small/large window icons. Existing launcher shortcuts reference a
content-named icon file to avoid reusing a cached executable icon after updates.

app, window, shortcut and installer icon. The transparent artwork includes
dedicated Windows icon sizes from 16 through 256 pixels.

Native WinUI 3 launcher with Windows 11 styling, Mica, system/light/dark themes,
sample lobby browsing, mod subscription review, separate Meta PC/Steam payloads,
verified caching, a subscription library, and GitHub-backed app updates.

Early launcher preview: sample JSON files only. Live accounts, hosted mods,
the in-game menu and actual game joining are not connected. No game files are
included or changed. SDK authoring tools remain a later milestone.

Visual C++ prerequisite if it is missing. Settings and subscriptions remain
outside the app installation and are preserved across updates.
