Version 0.3.0 connects the native WinUI launcher to a persistent HTTPS crew
service. Create an account, save its recovery code, add friends, discover
published packs, review subscriptions, host a four-person launcher room and
share invitations. Meta PC and Steam payloads retain separate resolution and
verification. Guests can join the launcher room and mark their pack ready.

The backend provides verified uploads, immutable releases, publisher identity,
owner-approved publishing, friend acceptance, blocks, private invitations,
capacity limits, expiring room leases, account recovery and moderation.
Saved sign-in tokens are encrypted for the current Windows user. Existing
sample lobbies remain available through Online -> Try sample lobbies.

Game installation and gameplay are unchanged. The game plugin, automatic
in-game lobby advertisement/joining and mod activation are not connected.
The SDK remains deferred until individual mod types are tested.

Install the Windows x64 Setup.exe asset. The installer handles the native
Visual C++ prerequisite if missing. The updater preserves existing settings,
subscriptions and the Starfleet/spanner icon registration.
